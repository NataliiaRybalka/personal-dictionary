- Два таба на две страницы:

1. Ввод слова: три поля - "Слово" / "Word", "Транслитерация" / "Transliteration", "Перевод" / "Translation"

2. Список сохраненных слов с поисковой строкой, кнопками "Экспорт" "Импорт" / "Export" "Import", выбором сортировки.

- Ввод и сохранение слова, его транслитерация, перевод. Каждое слово - это объект и храним все в массиве. strim(). Минимум 1 символ, не считая пробел, в обязательных полях.

[
    {
        "translation": str,
        "transliteration": str | null,
        "word": str,
    }
]


- Отображение нескончаемым слов списком с тремя колонками.

| перевод | транслитерация | слово |

- Сортировка по дате добавления: старые -> новые / новые -> старые (old -> new / new -> old). Выбор сохранить в local storage.


- Поисковая строка: ищет по всем полям.


- Язык приложения - взять язык системы. Дефолт - english. При первой загрузке приложения дать юзеру выбор: english или русский.


- Экспорт в csv / импорт из csv. При импорте проверять: если translation и word и transliteration уже существуют (все три поля совпали на 100%), то это слово не добавляем.

- Долгим удерживанием открывается модалка: Удалить / Редактировать (Delete / Edit).

При нажатии на Удалить - переспрашивать "Вы уверенны?" "Are you sure?".
При нажатии на Редактировать - переходить на таб "Новое слово" и предзаполнять поля выбранным словом.
