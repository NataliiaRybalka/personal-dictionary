- Ввод и сохранение слова, его транслитерация, перевод. Каждое слово - это объект и храним все в массиве.
[
    {
        "translation": str,
        "word": str,
        "transliteration": str,
    }
]

- Отображение нескончаемым слов списком с тремя колонками.
| перевод | транслитерация | слово |

- Сортировка по дате добавления: старые -> новые / новые -> старые

- Поисковая строка: ищет по всем полям.
